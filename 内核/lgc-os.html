项目介绍

lgc-os 是 lightfl0w 在 B站公开发布、使用配套 lgc 语言编写的 x86-64 实验内核，包含 GDT／TSS、分页、中断、抢占任务、RAMFS、ELF64 装载和限定 Linux ABI。微内核与自举能力按作者定位及具体源码分别记录。 资料概述

这是有自身启动目标和硬件特权初始化路径的实验内核。kernel/os.lg使用@boot，调用GDT、IDT、分页、系统调用、PIC/PIT和进程初始化，再进入shell；build.py通过lgc生成lgc-os.img。微内核名称属于作者定位。服务隔离与IPC架构边界继续待核实。 源码可见；微内核名称为作者声明 [lo7] [lo8] [lo9] [lo19]

体系结构与实现

固定源码采用PML4/PDPT/PD/PT分页结构、x86-64 MSR系统调用与64位寄存器保存；构建脚本使用qemu-system-x86_64。已核目标为x86-64。 源码可见 [lo9] [lo11] [lo13] [lo19]

lgc：内核主要源码；.lg文件及asm机器码字节。 源码可见 [lo8] [lo9] [lo11] [lo21]

Python / Shell / C：构建与测试脚本、用户示例。 源码可见 [lo19] [lo20] [lo21]

启动

@boot入口生成可引导内核镜像；README说明BIOS将首扇区载入，内核占后续扇区。引导生成器属于配套lgc，具体二进制版本绑定待核实。 源码可见与作者声明 [lo7] [lo8] [lo19] [lgc-boot-example]

任务调度

core.lg设置MAXPROC=8，维护FREE/READY/RUN/ZOMBIE状态、每任务CR3与内核栈。pick_next轮转寻找READY任务，IRQ0分发进入sched_irq并切换寄存器帧和页表。 源码可见 [lo10]

内存管理

mm.lg从0x1000000至0x4000000按4KiB递增分配页帧，为地址空间创建PML4/PDPT/PD/PT并按缺页映射用户页。core.lg设置页表权限位；完整内存隔离与W^X保证待独立验证。 源码可见 [lo9] [lo13] [lo29]

文件系统

fs.lg提供32个RAMFS文件槽，每个新文件预留1MiB；ata.lg以PIO端口读写扇区，shell的save命令调用ata_write及flush。 源码可见 [lo15] [lo16] [lo18]

设备驱动

VGA文本缓冲位于0xB8000；键盘代码轮询0x60/0x64并译码，串口使用COM1，定时中断使用PIC/PIT。 源码可见 [lo9] [lo17]

用户程序与兼容接口

ELF加载器读取64位入口与program headers，对PT_LOAD段复制文件内容并清零BSS。shell创建地址空间、初始栈和用户进程，提供exec/bg/ps。 源码可见 [lo14] [lo18]

系统调用分发覆盖read/write/open/close、部分stat、mmap/brk等Linux x86-64编号。mprotect/munmap等编号直接返回0，未知编号返回-38。具体应用兼容性按已实现接口逐项核验。 源码可见 [lo11] [lo12]

自举流程

测试脚本向客体发送exec lgc.elf os.lg os.bin及save命令，随后由宿主提取镜像、复制预载文件区并再次启动QEMU，再运行hello_c和a.lg编译测试。该脚本记录内核自举往返设计。 源码可见 [lo20]

README将运行自举版lgc、静态glibc C程序及自举往返列为完成项。 作者声明 [lo7]

配套编译工具
