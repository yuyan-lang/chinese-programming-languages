项目介绍

AntzOS 是 AntzUhl（CasterWx）在博客园公开开发过程的 x86 学习型内核，使用 C 与汇编实现图形终端、键盘事件、计时和简易文本编辑，构建链采用 Haribote／OSASK 相关工具及组件。 资料概述

这是采用 Haribote／OSASK 相关构建组件的个人学习内核。BIOS 汇编设置显示、GDT 与 CR0 保护模式，载入 C 内核；HariMain 初始化中断、PIT、键盘与图形终端。UNIX-based 保留为作者目标。 源码可见 [az1] [az2] [az3] [az4] [az6]

体系结构与实现

x86 32 位保护模式；asmhead.asm 以 i486p 指令集设置 GDT 与 CR0，并通过远跳转进入内核。 源码可见 [az3]

C 与 x86 汇编；Makefile 使用 nask、cc1、gas2nask、obj2bim 和 bim2hrb 生成 antz.sys 与 antz.img。 源码可见 [az2] [az3] [az4]

启动

BIOS 路径调用 VBE，支持失败后转入 320×200 模式，随后设置保护模式、复制内核并初始化堆栈。 源码可见 [az3]

中断与输入

GDT／IDT 与 PIC 初始化、键盘／鼠标 FIFO 及 PIT IRQ0 路径可见；主循环消费输入事件并重绘终端。 源码可见 [az4] [az5] [az6]

图形终端按键分派 version、reset、vim、vimshow 等命令，vim 分支维护固定文本行缓存；定时器驱动运行时间与动画重绘。 源码可见 [az4] [az5]
