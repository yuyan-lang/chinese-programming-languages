项目介绍

TextOS 是 Maouai233（ljQAQ233）维护的 x86-64 实验操作系统项目，采用 C 与汇编实现内核，配套 SigmaBoot 引导器和用户态程序。当前源码包含 UEFI 与 Multiboot 启动、任务调度、内存管理、VFS、设备驱动及 ELF 用户程序加载。 [tx2] [tx5] [tx6] [tx7] [tx11]

这是配套引导器、内核及用户态的实验操作系统。SigmaBoot 读取 ELF 内核并退出 UEFI Boot Services 后转交控制；独立内核构建生成 kernel.elf，内核自行初始化中断、内存、任务和设备。 源码可见 [tx5] [tx6] [tx7]

配套引导器名称为 SigmaBoot；源码仓库名称为 textos-dev。[tx2] [tx3]

体系结构与实现

README 明确为 x64；固定内核架构目录与构建入口为 x86_64，包含 UEFI、Multiboot、GDT、中断和 AP 入口。 作者声明与源码可见 [tx2] [tx9] [tx10]

固定内核构建采用 C11、freestanding 与 nostdlib 选项；x86-64 启动、中断和任务切换使用汇编。 源码可见 [tx6] [tx9] [tx10]

启动

SigmaBoot 调用 KernelLoad 读取 ELF，取得内存映射并调用 ExitBootServices，随后将引导参数和入口地址传给内核。 源码可见 [tx5] [tx26]

kernel_main 初始化 GDT、IDT、ACPI、APIC、内存、任务、设备与系统调用；initproc2 组织挂载与设备节点后调用 /bin/init。 源码可见 [tx7] [tx11]

调度

task.c 通过循环扫描任务表选取 TASK_PRE 任务，递减并恢复时间片计数，更新 TSS 与 CR3 后调用上下文切换；同时定义阻塞、唤醒和睡眠接口。 源码可见 [tx12]

内存管理

pmm.c 从 UEFI 或 Multiboot 内存映射建立空闲区链表，提供连续页分配、占用区保留和页释放。 源码可见 [tx13]

vmm.c 包含规范地址处理、物理页分配与页映射入口，文件仍保存虚拟内存设计 TODO；README 将完整虚拟内存管理和写时复制列为待完成。 源码可见与作者声明 [tx14] [tx2]

文件系统

文件系统构建清单包含 VFS 操作、管道、FAT32、Minix、procfs 和 tmpfs。mount.c 按分区类型选择 FAT32 或 Minix 初始化；fat32.c 定义引导记录、FSInfo 和目录项结构。 源码可见 [tx15] [tx16] [tx17]

设备驱动

E1000 驱动定义收发描述符、寄存器和设备状态，初始化时选择端口或 MMIO 访问；中断路径调用 LAI 的 PCI 路由接口或 MSI。 源码可见 [tx18]

README 列出 PS/2、串口、IDE、帧缓冲、ACPI/LAI 与网络设备进展；AHCI/SATA 的检测项和 MSI 的测试提示单独记录。 作者声明 [tx2]
