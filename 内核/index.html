本板块收录在B站、源码平台、项目官网及技术社区公开发布的操作系统内核，涵盖个人实验、教学和社区项目。条目引用原作者资料，记录架构、启动、调度、内存、文件系统、驱动和版本沿革。

资料按「作者声明」「原作者演示」「源码可见」「仓库元数据」「运行核验」标明依据。作者及社区归属采用公开自述，功能记录对应具体版本。

已收录 26 项 · 最近条目核验：2026-10-30

  • 豫言操作系统

    豫言操作系统由豫言项目维护，包含 ARM64 与 AMD64 裸机内核、用户态执行器和中文命令壳。内核与用户态通过豫言工具链生成，作者文档记录了 QEMU 下的启动、交互与持久文件系统验证。

  • DragonOS

    DragonOS 是龙进发起、DragonOS 开源社区共同开发的 64 位自研内核项目，面向轻量云计算与 Serverless 场景，采用 Rust 开发并提供 Linux 二进制兼容接口。

  • xbook2

    xbook2 是胡自成（Jason Hu）开发的 x86 32 位开源内核，也是 BookOS 使用的内核。项目提供多进程与多线程、内存管理、文件系统抽象层和设备驱动，可以用于学习操作系统实现。

  • LuminaOS

    LuminaOS 是使用 C 与汇编实现的个人实验操作系统。2026 年 9 月快照保存 i386 与 LSP 应用阶段；10 月 11 日快照包含 x86-64 长模式启动、ELF64 装载和进程模块。作者的 v0.7.0 视频记录较早的命令行与桌面演示。

  • CoolPotOS

    CoolPotOS 是 XIAOYI12 发起、plos-clan 社区共同开发的实验操作系统，采用 C 与汇编实现 CP_Kernel。项目包含 Limine 启动接口、EEVDF 调度、伙伴分配器、VFS 与 Linux 兼容系统调用，作者于 2025 年公开发布 AMD64 版本视频。

  • Uinxed-Kernel

    Uinxed-Kernel 是 ViudiraTech 社区维护的 x86-64 类 UNIX 宏内核，主要采用 C 实现。项目包含 Limine 启动接口、EEVDF 调度、物理页分配、VFS 和 Linux 兼容系统调用接口。

  • OpenXJ380

    OpenXJ380 是 XINGJI Studios 维护的 x86-64 独立单体内核项目，采用 C、C++ 和汇编实现，包含 UEFI 引导、任务调度、内存管理、VFS、设备驱动与 XAPI 用户态接口。

  • NeoAetherOS／na-kernel

    NeoAetherOS 是由 VOID2913 开发、以 aether-os-studio 组织公开维护的 Linux 兼容操作系统项目。当前 na-kernel 保存内核和可加载模块，naos 系统工程提供用户态与镜像构建。内核主要使用 C 和汇编，部分模块使用 Rust。

  • TextOS

    TextOS 是 Maouai233（ljQAQ233）维护的 x86-64 实验操作系统项目，采用 C 与汇编实现内核，配套 SigmaBoot 引导器和用户态程序。当前源码包含 UEFI 与 Multiboot 启动、任务调度、内存管理、VFS、设备驱动及 ELF 用户程序加载。

  • HOS（HuangCheng72）

    HOS是HuangCheng72公开开发的教学／实验宏内核项目，采用C与汇编，保存x86及多个32位ARM平台的移植阶段。固定源码包含引导、分页、任务调度、用户进程、系统调用、RAMDISK及HCFileSystem；平台功能按各自阶段记录。

  • YiYiYa

    YiYiYa 是 evilbinary 维护的开源学习型操作系统，使用 duck 内核和独立应用、库子模块。公开源码包含多架构适配、线程调度、内存管理、VFS、ELF装载与设备驱动。

  • AntzOS

    AntzOS 是 AntzUhl（CasterWx）在博客园公开开发过程的 x86 学习型内核，使用 C 与汇编实现图形终端、键盘事件、计时和简易文本编辑，构建链采用 Haribote／OSASK 相关工具及组件。

  • CoreZ-OS

    CoreZ-OS 是 lightfl0w 在 B站公开发布的 x86-64 实验内核，以 C 与汇编实现独立引导、任务调度、内存与文件系统，配有用户进程和限定 Win32／GDI 兼容层。GitHub 仓库当前标记归档。

  • lgc-os

    lgc-os 是 lightfl0w 在 B站公开发布、使用配套 lgc 语言编写的 x86-64 实验内核，包含 GDT／TSS、分页、中断、抢占任务、RAMFS、ELF64 装载和限定 Linux ABI。微内核与自举能力按作者定位及具体源码分别记录。

  • QuantumNEC

    QuantumNEC 是 SegmentationFaultCD 开发的实验操作系统内核。当前 limine 分支面向 x86-64，采用现代 C++ 与汇编，包含 Limine 启动、MuQSS 调度代码、页内存分配、页表及系统调用服务框架。

  • racaOS

    racaOS 是 zzjrabbit 维护、历经多次重构的操作系统项目。当前 edition21 采用 Rust，面向 LoongArch64，围绕 Zodiac 框架、动态内核模块和内存管理组织。历史分支保存 x86-64 系统。

  • OS002

    OS002 是 Liu Chunyi（Liu_Chunyi／Chunyi1031）公开的 x86_64 实验操作系统项目。项目以 C 和内联汇编实现内核，使用 UEFI 引导，源码包含线程调度、时钟与键盘中断、物理内存管理和命令行测试入口。

  • VergeOS Open（NewEra Studio）

    新启年工作室发布的x86 32位爱好者操作系统。作者原片直接关联公开C与汇编仓库，固定快照包含Multiboot入口、内存管理、任务轮转、tar初始内存盘及设备驱动；原作者中文技术发布与源码关联已核，成员国籍待核实。

  • KunOS

    KunOS 是 hellopgrmm 公开发布的16位实模式汇编学习型操作系统，源码包含BIOS引导、命令解释器、外部应用分派与XKFS文件管理器。

  • MimicryOS

    MimicryOS 是 Annihilation006 发起、使用 C 与少量汇编的 x86-64 学习型操作系统。当前BOOTBOOT阶段包含独立ELF内核、固定堆、ATA PIO、PS/2键盘轮询、Shell和简化磁盘文件操作。

  • KrcyOS

    KrcyOS 是 KercyDing 使用 Zig 开发的 RISC-V 学习型内核，经 OpenSBI 启动，包含 Sv39 分页、内存分配、定时调度与用户态系统调用实验。作者主仓位于 KercyCode，GitHub 保存只读镜像。

  • hudos／hodos

    hudos 是双子星观测站发布的 ARM64 UEFI 承载实验内核与系统，包含自身 ELF 装载、EL0／SVC、页权限管理和父子协程；物理内存分配、通用设备服务及异步中断基础由固件提供。

  • BearOS／小熊操作系统

    BearOS（小熊操作系统）是宁净（嘟嘟熊／胖嘟嘟的超级熊）公开发布的x86学习型操作系统。作者技术文档记录32位保护模式内核、自定义任务调度与文件系统、中文输入、图形窗口及BasC应用。功能按作者文档阶段呈现。

  • NeoRunST

    NeoRunST 是热土工作室公开发布的x86-64实验操作系统。官方v0.13.0镜像包含GRUB、独立UEFI引导器及C/汇编ELF内核，当前内核的中断、页表、NEP任务调度与文件系统实现具有发行物静态依据。

  • HanOS（汉操作系统）

    HanOS 是 JW／jjwang 维护的 x86-64 操作系统，采用 C 与汇编实现内核，提供内存、调度、能力句柄 IPC 与用户态服务。作者将其定位为混合微内核；本条目按作者公开所在地记录中国关联，国籍待核实。

  • Halo-OS（bigbenben77，仓库发布阶段）

    Halo-OS 是bigbenben77（公开别名码农笨笨）发布的Rust操作系统项目，作者声明使用AI开发。2026-09-24仓库Demo虚拟盘内含UEFI引导器及独立x86-64 Rust ELF内核；本条按仓库文档与固定发行物范围记录，B站同名发布身份继续待核。
