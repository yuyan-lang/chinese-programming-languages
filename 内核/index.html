本板块收录在B站、源码平台、项目官网及技术社区公开发布的操作系统内核，涵盖个人实验、教学和社区项目。条目引用原作者资料，记录架构、启动、调度、内存、文件系统、驱动和版本沿革。

资料按「作者声明」「原作者演示」「源码可见」「仓库元数据」「运行核验」标明依据。作者及社区归属采用公开自述，功能记录对应具体版本。

已收录 7 项 · 核验日期：2026-10-10

  • DragonOS

    DragonOS 是龙进发起、DragonOS 开源社区共同开发的 64 位自研内核项目，面向轻量云计算与 Serverless 场景，采用 Rust 开发并提供 Linux 二进制兼容接口。

  • xbook2

    xbook2 是胡自成（Jason Hu）开发的 x86 32 位开源内核，也是 BookOS 使用的内核。项目提供多进程与多线程、内存管理、文件系统抽象层和设备驱动，可以用于学习操作系统实现。

  • LuminaOS

    LuminaOS 是面向 i386 的个人实验操作系统，使用 C 和汇编实现。项目包含引导程序、32 位保护模式内核、FAT16 文件系统、图形桌面及 LSP 格式应用。作者在 B 站发布了 v0.7.0 的命令行与桌面演示。

  • CoolPotOS

    CoolPotOS 是 XIAOYI12 发起、plos-clan 社区共同开发的实验操作系统，采用 C 与汇编实现 CP_Kernel。项目包含 Limine 启动接口、EEVDF 调度、伙伴分配器、VFS 与 Linux 兼容系统调用，作者于 2025 年公开发布 AMD64 版本视频。

  • Uinxed-Kernel

    Uinxed-Kernel 是 ViudiraTech 社区维护的 x86-64 类 UNIX 宏内核，主要采用 C 实现。项目包含 Limine 启动接口、EEVDF 调度、物理页分配、VFS 和 Linux 兼容系统调用接口。

  • OpenXJ380

    OpenXJ380 是 XINGJI Studios 维护的 x86-64 独立单体内核项目，采用 C、C++ 和汇编实现，包含 UEFI 引导、任务调度、内存管理、VFS、设备驱动与 XAPI 用户态接口。

  • NeoAetherOS／na-kernel

    NeoAetherOS 是由 VOID2913 开发、以 aether-os-studio 组织公开维护的 Linux 兼容操作系统项目。当前 na-kernel 保存内核和可加载模块，naos 系统工程提供用户态与镜像构建。内核主要使用 C 和汇编，部分模块使用 Rust。
