项目介绍

KrcyOS 是 KercyDing 使用 Zig 开发的 RISC-V 学习型内核，经 OpenSBI 启动，包含 Sv39 分页、内存分配、定时调度与用户态系统调用实验。作者主仓位于 KercyCode，GitHub 保存只读镜像。

独立 riscv64-freestanding 内核链接目标由 OpenSBI 交接；_start 设置内核栈，main 清理 BSS 后初始化陷阱、内存与 UART，再进入 S态或 U态实验路径。 源码可见 [kc2] [kc3] [kc4]

体系结构与实现

RISC-V 64 位，QEMU virt；链接基址 0x80200000。real_board 分支提供构建与刷写提示，具体实板型号和运行覆盖待核实。 源码可见 [kc2] [kc4]

Zig 与 RISC-V 汇编；固定 README 和构建入口采用 Zig 0.17.0。 源码可见 [kc1] [kc2] [kc3]

启动与程序入口

构建生成 krcyos，QEMU virt 通过 -bios 选择附带 OpenSBI，再通过 -kernel 加载该内核。 源码可见 [kc2]

内存管理

Sv39 三级页表建立区域映射和访问权限，更新 satp；内核初始化串联物理页、虚拟内存与堆管理。 源码可见 [kc3] [kc5]

调度与中断分工

调度器维护就绪与睡眠任务，通过定时陷阱选择下一任务并调用 switch_to 保存和恢复上下文。 源码可见 [kc6] [kc7]

用户态接口

U态系统调用分派 write、read、exit；write 校验文件描述符及用户缓冲区，read 返回0，exit 记录信息后进入 User Mode Ended. panic。 源码可见 [kc8]

源码测试入口

super 模式定义内存、堆、断点与任务调度实验；user 模式定义 write→exit 冒烟路径。宿主单元测试由独立 test 构建步骤组织；通过结果与内核运行分别待核实。 源码可见 [kc2] [kc10] [kc11]
