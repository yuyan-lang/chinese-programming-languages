项目介绍

OpenXJ380 是 XINGJI Studios 维护的 x86-64 独立单体内核项目，采用 C、C++ 和汇编实现，包含 UEFI 引导、任务调度、内存管理、VFS、设备驱动与 XAPI 用户态接口。

README 将项目定位为 x86-64 独立单体内核。固定源码包含 UEFI 交接、KernelMain、任务调度、物理内存分配和设备操作路径。 作者声明
