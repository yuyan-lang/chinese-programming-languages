语言介绍

道是 Carson 维护的多范式中文编程语言，采用缩进代码块与 .道 源文件。中文关键字涵盖定义、常量、函数、返回、如果、否则如果、否则、当、遍历、类型、逻辑和定义宏。公开源码以 Python 实现词法分析、语法分析、树遍历解释器以及字节码编译与虚拟机入口；仓库同时提供面向对象、函数式、逻辑编程和宏系统的文档与模块。

实现与运行环境

源码/main.py 的 run_source 依次调用 Lexer.tokenize 和 Parser.parse，默认交给 Interpreter.execute；--mode vm 路径调用 BytecodeCompiler.compile 与 VirtualMachine.run。tokens.py 提供中文词元映射，parser/modules/control_flow.py 解析条件与遍历，interpreter/statements/executor.py 第313—440行实现函数、返回及条件循环求值。bytecode/compiler.py 与 vm/core.py 提供字节码生成和指令分派。jit/compiler.py 的 _specialize 当前复制 CodeObject 指令与常量表，JIT 实际优化效果和原生机器码生成待核实。四范式完整覆盖及双模式语义一致性待核实。
