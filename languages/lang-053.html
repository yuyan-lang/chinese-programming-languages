函数 斐波那契(n) {
    如果 (n <= 1) {
        返回 n
    }
    返回 斐波那契(n - 1) + 斐波那契(n - 2)

实现与运行环境

cnsh_v21/tokens.py 把中文关键词映射为词元；parser.py 第333—474行实现函数、变量、条件、循环及返回解析。cnsh_v21/__init__.py 的 _parse 串接 Lexer.tokenize 与 Parser.parse，run_source 调用可选优化、类型检查及 Interpreter.run；严格类型拒绝由 strict_types 控制。cnsh_v2c/compiler.py 依次加载模块、插入追溯信息、审计、类型检查并调用 codegen，build 路径以 cc／gcc／clang 的 -std=c99 参数编译生成的 C 文件；codegen_c.py 具有类型映射、函数和条件语句输出。解释器正文在本次 Gitee 页面呈现平台限制提示，完整运行时内部实现待核实。
