语言介绍

Chinese++是基于Clang/LLVM的中文C/C++工具链，为关键字、预处理指令、入口名称和诊断正文提供中文写法，支持中英文在同一程序中混用。示例以“整数”“类型”“公开”“对于”“返回”等词组织程序。官方Windows线提供工具链发行包、中文标准库头及编辑器配置；官方Linux线公开编译器补丁、生成器、测试和打包资料，两条平台线分别演进。项目原创部分采用自定义源码可见许可，各上游派生部件按其许可记录。

分类与别名

Clang/LLVM中文C/C++工具链／中文关键字扩展；别名：ChinesePlusPlus、LinuxChinese++、LinuxChinesePlusPlus

设计与特征

中文关键字与Clang词元映射（公开补丁）；中文预处理指令及主函数入口映射（公开补丁）；中文诊断正文与英文回退（公开补丁）；Windows中文库层及Linux中文别名/C运行库层；Windows与Linux独立版本和编辑器配套

中文语法示例

双精度 合计(常量 std::vector<商品>& 货物) {
    双精度 和 = 0;
    对于 (常量 自动& 件 : 货物)      // 对于 = for，自动 = auto
        和 += 件.单价();
    返回 和;                        // 返回 = return
}

实现与运行环境

官方资料将底本记为LLVM/Clang 24.0.0git。Linux线的zh-keywords.patch使用AddKeyword将中文拼写注册到tok::kw_*，把“主函数”映射到main，并为中文预处理指令映射pp词元；zh-diagnostics.patch按诊断编号查找中文正文，配有英文回退和-fno-chinese-diagnostics开关。Windows固定树包含库头、安装脚本和发行二进制；Linux固定树提供核心修改补丁、生成器和测试。完整上游基线、补丁重放、发行包与源码对应性及运行能力待核实。

与其他项目的关系

Windows ChinesePlusPlus与LinuxChinesePlusPlus为同作者的Chinese++平台线，合并为一个语言项目。Linux README明确关联Windows官方库并说明分别演进。Afiredream/ChinesePlusPlusCompiler的GitHub parent/source均指向YoloLogic/ChinesePlusPlus，按同源分叉处理。中文大战代码为官网另列的配套编辑器；同作者ChinesePython、ChineseTypeScript和ChineseJava分别保留各自项目身份。
