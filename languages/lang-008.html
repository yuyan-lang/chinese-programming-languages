语言介绍

段言采用中文关键字和缩进式代码块，面向希望使用中文学习和编写程序的开发者。官方入门教程使用“设……为……”声明变量、“打印”输出内容，并以“段落……接收……”定义函数。教程还介绍条件、循环、交互式解释器和命令行工具。

语言特性与实现

官方教程介绍通过 Python 包管理工具安装，使用 duan run 运行源文件，使用 duan repl 进入交互环境；文档还介绍语法检查、语法树查看、调试及进阶语言特性。不同版本的功能应分别核实。
