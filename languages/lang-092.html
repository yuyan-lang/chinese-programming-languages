语言介绍

大雄语（DxLang）是一门以中文关键字组织程序的解释型脚本语言，作者将编译原理学习和个人技术展示作为项目目标。固定原仓提供中文需求设计、七个.dx例程和Python实现。程序以“大雄启动／大雄结束”包围语句，变量用“设…为…”定义，函数用“函”与花括号组织，条件、循环和返回采用“若／则／结束”“当”“循／在”“归”等词元。运行链由手写词法分析、递归下降解析、自有AST和树遍历求值器组成；文件运行、交互输入与命令行字符串入口均有源码。原例覆盖斐波那契、排序、猜数字及学校管理等场景。

中文语法示例

函 斐波那契迭代(n) {
    若 n <= 1 则
        归 n
    结束
    设 雄_a 为 0
    设 雄_b 为 1
    设 雄_i 为 2
    当 雄_i <= n 则
        设 雄_c 为 雄_a + 雄_b
        雄_a = 雄_b
        雄_b = 雄_c
        雄_i += 1
    结束
    归 雄_b
}

实现与运行环境

Python源码main.py的run_code依次调用DxLexer.tokenize、DxParser.parse与DxVM.run。dx_lexer.py定义汉字词元，并将连续标识符扫描结果与KEYWORDS集合匹配。dx_parser.py以递归下降方法生成ProgramNode、IfNode、WhileNode、ForNode及FuncDefNode等自有AST。dx_vm.py第81—100行明确自述树遍历解释器，execute按节点类型分派并递归求值；Scope对象保存作用域链，函数定义保存定义时作用域，调用创建局部作用域，归语句通过DxReturnSignal传递结果。dx_std.py登记中文数学、字符串、容器、随机和文件函数。固定main.py保存九项冒烟用例；通过状态待独立核验。
