语言介绍

PB 是 PengBooo／彭博在 nntandg/pb-lang 仓库发布的中文语法转译语言，面向中文编程初学者。程序以“定义、返回、如果、否则、对于、在、执行”等词汇组织函数、条件和循环，并保留缩进结构。实现采用 Python 词法分析与语句翻译，将中文源码转换成 Python 后执行，配套中文标准库封装、交互环境和命令行工具。0.3.1 推荐 .pb 扩展名，同时保留 .zhpy 及 zhpy 命令。原仓库提供完整中文测试程序和 wheel、源码发行包；作者维护的状态文件记载了 ZHPY／CHPY 改名为 PB 的过程。
