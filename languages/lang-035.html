语言介绍

CP语言以“变量、函数、如果、当、返回”等中文关键字组织程序，也提供对应英文关键字。公开仓库含C++词法、语法、语义分析、字节码生成及虚拟机实现，并包含LLVM ORC JIT代码和中文标准库名称。当前命令行另有将字节码与运行器封装为exe的build分支；README仍宣传的LLVM原生AOT路线与当前入口及构建清单不一致，不能将二者混为一谈。

分类与别名

中英双语关键字语言／字节码虚拟机与JIT实现；别名：cplang、恋语

设计与特征

中英双语关键字与UTF-8中文标识符；函数、条件、循环和递归（已核对样例及解析器）；可选参数/返回类型标注（解析器源码）；字节码编译与VM执行；LLVM ORC JIT实现及可选构建开关；字节码与运行器封装、交互式REPL

中文语法示例

函数 阶乘(n) {
    如果 (n <= 1) {
        返回 1;
    }
    返回 n * 阶乘(n - 1);
}

实现与运行环境

C++17实现独立前端与字节码VM；include/lexer/token.hpp提供中英关键字表，src/lexer/lexer.cpp调用该表，parser_decl.cpp/parser_stmt.cpp构造函数及控制流AST。src/codegen/codegen.cpp生成字节码，src/main.cpp调用Compiler和VM；src/jit/orc_jit.cpp含LLVM LLJITBuilder/addIRModule/lookup代码，由CMake的LLVM开关条件构建。当前main.cpp的build分支序列化字节码并附加到运行器exe。仓库仍保留旧LLVM AOT源码和一个返回false的AOT占位文件，但当前CLI没有README所示-a入口，CMakeLists.txt没有AOT目标；本次不认定原生AOT在当前版本可用。
