语言介绍

自然派是 Amo-Zeng 开发的中文解释型编程语言，以前缀函数调用表达运算、条件与循环。函数按所需参数个数组合后续表达式，中文“令、若、循、函”等形式用于赋值、分支、遍历和函数定义。文档还提供数组、字典、代码块、类与模块机制，使用“@@”分隔同一行中的语句。项目发布 Python 运行入口、中文程序、扩展模块和用法文档；2025 年更新加入自然派文件导入与 Python 模块导入。当前公开的“密自然派”采用混淆后的 Python 源码形式，配套模块通过按参数个数组织的函数字典注册接口。作者提供交互、命令和文件运行方式。本条目的语法依据固定文档及程序，运行效果按作者说明记录。

设计与特征

前缀表达式以中文函数名表示运算，调用按函数参数个数组合。；“令、若、循、函”分别表达赋值、条件、遍历和函数构造。；“@@”分隔同行语句，“【】”组合代码块；文档提供数组、字典、类和模块。；Python 扩展模块按参数个数通过“函子、函丑”等字典注册函数。
