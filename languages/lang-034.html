语言介绍

玄铁（XuanTie）是面向中文母语开发者的开源编程语言，项目以语言、编译器、标准库、渲染引擎和开发环境组成的桌面开发栈为主要定位。语法使用“设、函、若、返、引”等中文关键词，提供字符串插值、数组与字典、类型定义、继承、结果容器及异步并发。仓库同时保存 Go 种子编译器和用玄铁编写的编译器源码；两条编译路径均生成 LLVM IR，再调用本机工具链构建原生程序，运行时由 C 实现并包含原子引用计数。项目还配有铁铺包管理器、铸造厂 IDE 和官方文档，采用 MIT 许可证。当前发行版本为 v1.0-rc.3，处于正式版前的候选阶段，作者建议这一阶段用于小项目。作者在 README 中声明大量代码由大模型生成。

实现与运行环境

Go种子实现包含lexer、parser、evaluator及compiler；main.go的tie路径调用NewLLVMCompiler().Compile()生成.ll，优先调用clang将IR编译为.o，再通过gcc驱动链接C运行时。xuantie_compiler/玄铁.xt加载词法、语法分析和编译模块，创建词法分析器、语法分析器和编译器，生成LLVM IR并调用clang与gcc驱动。runtime/以C实现运行时，xt_retain/xt_release通过原子操作维护引用计数；自举产物一致性、性能和跨平台执行结果待核实。
