语言介绍

使用中文关键字、中文标识符与花括号/分号语法的编译型语言。仓库包含 .at 示例、以 .at 编写的词法分析器、语法分析器、语义分析器、代码生成器、汇编器和链接器源码；已检查的编译入口串联这些模块，目标为 Windows x86-64。此次仅作源码与发布元数据核实，未编译或运行程序。

设计与特征

词法表实际映射“设、如果、又如果、否则、循环、返回值、声明、函数、类、继承”等中文关键字，并含中文字符标识符识别逻辑。；语法分析器含变量声明、函数声明、条件、循环、类与接口等解析分支；示例使用中文函数名和内建打印调用。；编译入口可见词法分析、解析、语义分析、汇编输出、COFF 对象生成与链接步骤；链接器定义 AMD64 目标。；仓库提供 .at 编译器源码、含嵌入汇编的 .at 运行时、C 运行时相关文件及十六进制二进制种子。；自举、M:N 调度、AUI、OpenGL/Vulkan 和包管理为项目宣称或对应源码/示例所展示的方向，其完整性、可运行性与性能未由此次研究验证。

实现与运行环境

主入口 self-hosted/atlv1.at 引入 atl_lexer.at、atl_parser.at、atl_semantic.at、atl_codegen.at、atl_assembler.at、atl_linker.at 等 .at 模块；907–950 行可见 lex → parse_program → sem_analyze → codegen → assemble/write_coff → link。self-hosted/atl_rt.at 使用“汇编(...)”嵌入 x86-64 汇编；runtime/ 另含 xt_runtime.c、xt_threadpool.c、xt_net.c 等 C 文件。seed/seed_builder.c 是解码并校验十六进制种子的物化器，输出 atlv1.exe 和 atl_rt.obj，并非从 C 源码重建语言编译器。rebuild_atlv1.ps1 依赖预存 AT-V1.exe；rt_build.ps1 依赖 atlc.exe、Python 与 NASM。GitHub 标记主要语言为 C 不能代替对实现结构的判断。
